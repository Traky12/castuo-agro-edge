## Usage boundary

Approved usage is limited to repository identity, documentation, public README navigation and governed ecosystem references. Brand assets must not be placed over secrets, credentials, private endpoints, customer data, execution envelopes or evidence artifacts in a way that could conflate identity with proof.

Any claim about implementation, testing, operation, staging, production, certification or promotion must be supported by its own provenance, environment, immutable artifact, evidence and human review. A brand check passing is only a surface-policy result.

## Validation

The workflow `CASTUO Brand Surface` validates the controlled README block and checks that the public surface does not attach prohibited operational or regulatory claims to the logo. This check is independent from conformance, security, evidence, staging execution and promotion gates.
